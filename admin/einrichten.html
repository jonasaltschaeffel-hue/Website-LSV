Bearbeitungsmodus einrichten

Hier verbindest du die Website einmalig mit GitHub und legst dein eigenes Passwort fest. Der GitHub-Schlüssel wird in deinem Browser mit diesem Passwort verschlüsselt und nur verschlüsselt gespeichert.

1. GitHub-Schlüssel erstellen

  1. Bei GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: „Only select repositories“ → nur das Website-Repository.
  3. Permissions → Repository → Contents: „Read and write“. Sonst nichts.
  4. Ablaufdatum wählen (max. 1 Jahr) und den Schlüssel unten einfügen.
